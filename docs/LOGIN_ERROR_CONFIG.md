# 登录错误提示配置

GM → 管理设置 → 登录错误提示。

- 错误码固定，默认玩家提示及原因 TIPS 随代码提供，TIPS 不发给玩家。
- 当前服务器登录拒绝的12种错误可自定义，最多300字。留空或恢复默认后保存即可恢复默认文案。
- 其余兼容或本地错误为只读；未连接服务器的 DNS、TLS、断网等错误仍使用组件本地诊断。
- 保存有版本冲突检查，数据库 login_error_rules_audit 保留前后记录。
- 首次需要部署新的游戏服务器、GM 后端和登录组件；旧组件忽略新增字段，保持原提示。
- 新组件从 TLS 登录回复读取 error_message，始终保留原 error 错误码。
- 后续 GM 保存无须重启。拒绝登录时最多每5秒读取一次配置；读取超时150ms后回退缓存/默认，不阻断错误回复，不使用战斗锁。
- 生效以数据库可用为前提；数据库不可用时不会获取新文案。

## 构建包

GM管理器：完整Windows运行目录。
登录组件/OnlineBridge.exe：待发布的新组件；需通过既有发布工具更新组件文件清单与哈希，不要只替换玩家目录EXE。
线下服务端/kungfu-server.exe：待替换Windows服务器。
线上服务端：Linux amd64游戏服务器、管理CLI、GM HTTP后端。
login-error-schema.sql：仅新增配置及审计表，不修改玩家数据。

本包没有部署到线上，也没有重启线上或线下服务器。首次部署应先迁移数据库，再替换对应服务器/GM后端；登录组件按现有OSS发布流程发布。
