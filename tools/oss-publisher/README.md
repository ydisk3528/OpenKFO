# OSS 发布工具 1.2.0（三区一键同步）

固定发布到原 OSS：openkfo / cn-hangzhou。目标为三区，SSH 入口 aaa.vxfnqfjdr.top，用户 root，固定校验已核实的 SSH 主机密钥；服务端再次校验数据库名 kungfu_realm3，不会同步二区。

## 使用
1. 打开 OSS发布工具-三区一键同步.exe。
2. 选择最新 OSS 上传包，当前为 2026.10.01-realm3-oss.2。普通登录器 ZIP 不能用于发布。
3. 本机自动读取加密保存的 OSS 凭据及三区密码。换电脑或 Windows 用户时重新填写。
4. 先“仅检查压缩包”和“预览合并清单”。
5. 点击“一键发布并同步三区”，确认维护提示。工具上传并校验资源、预检三区，再发布版本入口，最后同步配置与发布版本。
6. 哈希改变、发布版本改变、或服务器停止时，都需要允许启动/重启。服务器先停止再同步启动。当前新版服务端助手兼容 CentOS 7。
7. 必须看到三区同步成功，再用旧二区正式登录器更新、登录验证。测试版若关闭自动更新，需要安装完整正式登录器。
8. OSS 成功但服务器失败时，使用“重试同步当前版本”，不要随意换版本重发。服务器发现 recovery.json 会停止，须先核对恢复记录。

## 数据范围
工具不会迁移玩家数据，不修改商城价格/推荐顺序，也不替换游戏服务器二进制。配置变化时验证关卡兼容性、迁移地图哈希绑定；不兼容会在版本入口发布前中止。
当前游戏服务停服状态会由发布同步流程在用户确认后启动；本次工具部署本身没有启动游戏服务，也没有发布 OSS。
GM API 是独立服务，此工具仅控制 kungfu-go，不自动启动 GM API。

## 安全及历史资源
密码和 OSS 密钥保存在当前用户 %LOCALAPPDATA%/OpenKFO/Publisher/credentials.dpapi；不在源码、EXE、上传 ZIP 或 OSS 中。Bucket、地域、下载地址固定不可编辑。
旧“二区一键同步”工具不要再使用。当前根域名 DNS 不可用，SSH 采用已核实可连接的 aaa 子域名；不经过 Cloudflare HTTP 隧道。
最新客户端清单继承历史文件，未变文件复用旧 OSS 地址；不要删除仍被清单引用的 releases 对象。
发布顺序为资源和清单先、version/version.json 最后；已发布的同版本对象不覆盖。公告独立发布，不会因为选择 ZIP 自动改变。
